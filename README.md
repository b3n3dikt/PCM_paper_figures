# PCM Paper Figures

See **instructions.html** (open in any browser) or **instructions.pdf** for the
full documentation: what's in the data, which script makes which figure/table,
and how to run everything.

Quick start:

```bash
cd code
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 run_all.py
```
