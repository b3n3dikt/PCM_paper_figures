PCM Paper Figures

Precision Confidence Mapping — action mode network (AMN) targeting. Data, code, and instructions to regenerate Figure 4, Table 1, Figure 5C/D, Supplementary Figure 1, Supplementary Table 1, Supplementary Figure 2, and every other statistic reported in the paper.

Quick start

cd PCM_paper_figures/code
python3 -m venv .venv && source .venv/bin/activate   # optional but recommended
pip install -r requirements.txt
python3 run_all.py

That runs all nine scripts in order and writes every figure/table into outputs/, mirroring the folder layout described below. Runtime is well under a minute — nothing here needs a cluster. Requires Python ≥3.9; tested with pandas, numpy, scipy, and matplotlib per requirements.txt.

The data/ folder ships pre-built — you don't need to run code/prep_data.py yourself; it's included only in case you ever need to re-derive the data files.

Data dictionary

data/combined_metrics/combined_metrics_used_in_paper.csv

Long-format table, one row per (subject × threshold × metric × network × exploratory-minutes) combination.

ColumnMeaning
SubjectOne of PFM3T7T01–PFM3T7T04 (N=4).
ThresholdPCM confidence threshold, 0.0–0.99. Vertices below threshold are excluded from that map before computing metrics.
MetricOne of PPV_cort, TPR_cort, FPR_cort, TNR_cort, FNR_cort, DC_cort (Dice), MIn_cort (normalized mutual information), plus raw counts TP_cort/FP_cort/FN_cort.
NetworkOne of the 15 canonical networks: AMN, Aud, DAN, DMN, FP, MTL, PMN, PON, SCAN, SMd, SMl, Sal, Tpole, VAN, Vis.
ExpMinLength (minutes) of the exploratory data compared against the reference: 5, 10, 15, …, 70.
RefMinLength (minutes) of the reference data. Always 70 (the fixed ground-truth reference used everywhere in the paper).
ValueThe metric's value for that row.

data/figure5_conditions/*.csv

Four files — TM_5min.csv, TM_70min.csv, PCM_5min_thr0.99.csv, PCM_70min_thr0.99.csv — used only for Figure 5C/D. These have a completely different design from the combined metrics file above: each row compares one subject's exploratory-half map against one subject's reference-half map, both at the same fixed duration (5 or 70 minutes) — this is what lets Figure 5 measure within- vs. between-subject agreement.

ColumnMeaning
SubjectAlways allsubs — a placeholder, not meaningful here.
SubjIndex_Exp, SubjIndex_RefSubject index 1–4 for the exploratory and reference map respectively — not minutes, despite these columns being called ExpMin/RefMin in the original raw files. Renamed here specifically to avoid that trap.
SubjectID_Exp, SubjectID_RefAdded in this package: the actual PFM3T7T0X ID for each index, so you don't have to cross-reference a separate key.
Threshold, Metric, Network, ValueSame meaning as the combined metrics file.

Diagonal rows (SubjIndex_Exp == SubjIndex_Ref) are within-subject comparisons; off-diagonal rows are between-subject comparisons (averaged over the 3 other subjects per subject, per the manuscript's Methods).

data/suppfig3_nmi/*.csv

Two files, used only by other_stats_suppfig3_nmi.py. pcm_thr0.99_matched_duration_pairs.csv: all 4×4 subject-pair whole-map NMI (MIn_cort) comparisons at matched duration (both sides 5 or both sides 70 minutes, PCM confidence maps thresholded at 0.99) — same within/between-subject logic as the Figure 5 condition files above (diagonal = within-subject, off-diagonal = between-subject). standardTM_within_between_stats.csv: the same within/between comparison for genuine Standard Template Matching, already summarized to mean/SD/paired-t (per-subject-pair values weren't available for this method, only its finished statistics).

The "TM" conditions use genuine, independently-run Standard Template Matching data (ExpMethod-TM source files) — confirmed to reproduce every reported Figure 5 quantity in the current manuscript exactly, including the Holm-corrected family of 4 tests (Methods: "Holm–Bonferroni correction applied across the four comparisons"). An earlier version of this package used a different source file (PCM confidence maps at threshold=0, standing in for TM) that matched an older draft of the manuscript but not the current one — that's fixed; see the Validation section below for the exact numbers checked.

Supplementary Figure 3 (whole-map NMI within/between-subject reliability, TM vs. PCM@0.99, 5 vs. 70 min):

Script
code/other_stats_suppfig3_nmi.py
Data
data/suppfig3_nmi/standardTM_within_between_stats.csv (genuine Template Matching side) and data/suppfig3_nmi/pcm_thr0.99_matched_duration_pairs.csv (PCM side, all 4×4 subject-pair comparisons at matched duration — within-subject vs. between-subject NMI is computed directly from these)
Output
outputs/other_stats/suppfig3_nmi_within_between.csv

Unlike every other figure in this package, Supp Fig 3 compares two independent halves of data of the same duration (Half 1 vs. Half 2, both 5min or both 70min) rather than exploratory-data-vs-fixed-70min-reference — see Supplemental Materials p.6–7. One thing worth knowing about the TM side specifically: Standard Template Matching has no PCM confidence threshold, so it isn't part of the usual threshold sweep — its per-subject raw comparisons weren't available, only its already-computed within/between summary statistics, which are used directly rather than recomputed from scratch.
